# AcaDivity — Academic Activity Report

Aplikasi pencatatan kegiatan **Tri Dharma & Penunjang** dosen, lengkap dengan cetak **Laporan Kerja Bulanan (LKB)** dalam format PDF.

- **Tampilan (frontend):** di-hosting di GitHub Pages (repo ini).
- **Server & data:** Google Apps Script + Google Sheets + Google Drive (tidak disimpan di GitHub).

Alamat server diatur di [`config.js`](config.js).
